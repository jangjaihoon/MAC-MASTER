# 공문 초안 자동 생성 프롬프트

## 사용법
아래 프롬프트를 Claude에 붙여넣고 [] 안의 내용을 채워서 실행하세요.

---

## 프롬프트 템플릿

```
한국장애인고용공단 표준사업장 지원 업무 담당자로서 아래 내용의 공문을 작성해주세요.

- 수신: [수신 기관명]
- 제목: [공문 제목]
- 요지: [공문의 핵심 내용 1~3줄]
- 첨부: [첨부 서류 목록 (없으면 "없음")]
- 특이사항: [강조할 내용 또는 기한 등]

형식:
- 한국장애인고용공단 공문 양식에 맞게 작성
- 간결하고 명확한 행정 문체 사용
- 본문은 3단락 이내로 구성
```

## 절감 효과
- 작성 시간: 30분 → 10분
- 월 20건 × 20분 = **월 400분 절감**
